Last updated: 2026-08-01.

## Steps

1. Start with the exported thumbnail file, not the editor preview.
2. Open the pre-upload checklist to verify size, ratio, format, and file weight.
3. If the file fails because it is too heavy, open the thumbnail file-size guide before compressing it again.
4. If the file fails because it is blurry or compressed, open the blurry thumbnail troubleshooting guide.
5. If the failure is format-related, compare JPG, PNG, WebP, and AVIF tradeoffs.
6. If the thumbnail depends on text, check whether the text is readable at small sizes and whether the video title repeats or completes the image.
7. If the image may belong to another YouTube asset type, use the YouTube image sizes hub before applying thumbnail-only rules.

## Common Failure Pattern

Many thumbnail problems are diagnosed too late. The image looks good in Canva, Photoshop, Figma, or a video editor, but the exported file is too large, too soft, not truly 16:9, saved in the wrong format, or unreadable in a small feed preview.

Use the pre-upload checklist first. Then choose the repair route based on the actual failed check.
