# Social Media Image Checker Workflow

Last updated: 2026-08-01.

Use this workflow when one exported image may belong to Instagram, Facebook, LinkedIn, Open Graph, ecommerce, marketplace, or a creator platform, and the publishing surface is still unclear.

Primary ImageSizeKit route:

https://imagesizekit.com/social-media-image-checker/

Related workflow guide:

https://imagesizekit.com/check-social-media-image-size-before-upload/

## Steps

1. Start with the final exported image file.
2. Open the Social Media Image Checker before choosing a platform-specific guide.
3. Check width, height, aspect ratio, file size, and format locally in the browser.
4. Read the routing recommendation: square post, vertical story, wide banner, Open Graph card, product image, marketplace image, or creator thumbnail.
5. Open the most specific ImageSizeKit guide for the final surface before upload.

## Common Failure Pattern

The phrase "social media image" is too broad. A 1080 x 1080 square, 1080 x 1920 vertical image, 1584 x 396 LinkedIn banner, 1200 x 630 Open Graph card, and marketplace listing image all need different checks.

Use the checker to identify the file and route it before applying a platform rule.
